# מתאם הזמנים

לוח שבועי משותף (ראשון–שבת, 10:00–21:00). כל משתתף מסמן בצבע שלו מתי הוא פנוי, וכולם רואים בזמן אמת מתי כולם יכולים להיפגש. בלי הרשמה ובלי מיילים: שולחים קישור וזהו.

## מה יש בתיקייה

| קובץ | למה הוא |
|---|---|
| `index.html` | הכלי עצמו |
| `database.rules.json` | כללי האבטחה של מסד הנתונים (מדביקים ב-Firebase) |
| `README.md` | המדריך הזה |

## מצב נוכחי

הכלי כבר מחובר למסד הנתונים בפרויקט Firebase `meeting-sync-a00a9` (אזור europe-west1), והכללים פורסמו. כדי להפעיל אותו צריך רק להעלות את `index.html` ל-GitHub Pages (שלב 3).

ניהול המסד: console.firebase.google.com → meeting-sync → Databases & Storage → Realtime Database.

## התקנה חד-פעמית (לתיעוד, או להקמה מחדש בפרויקט אחר)

### שלב 1: מסד נתונים חינמי ב-Firebase

1. היכנסו ל-**console.firebase.google.com** עם חשבון Google.
2. **Create a project** → שם, למשל `meeting-sync` → אפשר לכבות את Google Analytics → **Create project**.
3. בתפריט: **Build → Realtime Database** → **Create Database**.
4. מיקום: **Belgium (europe-west1)** → **Next**.
5. בחרו **Start in locked mode** → **Enable**.
6. עברו ללשונית **Rules**, מחקו את כל מה שכתוב שם, הדביקו את כל התוכן של `database.rules.json` ולחצו **Publish**.
7. חזרו ללשונית **Data**. למעלה מופיעה כתובת שמתחילה ב-`https://` ומסתיימת ב-`firebasedatabase.app` (או `firebaseio.com`). העתיקו אותה.

### שלב 2: הדבקת הכתובת בכלי

ב-`index.html` חפשו את השורה:

```
databaseURL: ""
```

והדביקו את הכתובת בין המירכאות:

```
databaseURL: "https://meeting-sync-xxxx-default-rtdb.europe-west1.firebasedatabase.app"
```

זה השינוי היחיד בקוד.

### שלב 3: GitHub Pages

בדיוק כמו בשאר הרפוזיטוריז: מעלים את הקבצים לרפוזיטורי חדש, ואז **Settings → Pages → Deploy from a branch → main / (root)**.

### שלב 4: בדיקה

פתחו את האתר. מתחת לכותרת צריך להופיע **"מסונכרן"** עם נקודה ירוקה. אם מופיע "מצב הדגמה", הכתובת לא הודבקה. אם מופיעה הודעת שגיאה כתומה, בדקו שהכתובת הועתקה במלואה ושהכללים פורסמו (שלב 1, סעיף 6).

הבדיקה הכי טובה: פתחו את האתר בשני טלפונים, הצטרפו בשני שמות שונים וסמנו. הסימונים צריכים להופיע בטלפון השני תוך שנייה.

## שימוש

- **שיתוף הקישור** פותח את חלון השיתוף של הטלפון (וואטסאפ וכו').
- **לוח חדש** יוצר לוח נפרד עם קישור משלו, לקבוצה אחרת או לשבוע אחר. הלוח הקודם נשאר בקישור שלו.
- **מספר משתתפים** (2 עד 16) קובע כמה אנשים יכולים להצטרף.
- **סימון ופירוט** מראה את הצבע של כל אחד. **חפיפה** מראה כמה אנשים פנויים בכל שעה.
- כל טלפון זוכר מי המשתמש שלו. מי שנכנס ממכשיר אחר לוחץ על השם שלו ברשימה, לא מצטרף מחדש.

## טוב לדעת

- **עלות:** התוכנית החינמית של Firebase (Spark) מספיקה בהרבה. לא צריך להכניס כרטיס אשראי.
- **פרטיות:** כל מי שיש לו את הקישור יכול לראות ולסמן בלוח. אין סיסמה. לקבוצה רגישה יותר, השתמשו ב"לוח חדש": הקישור שלו כולל קוד אקראי שקשה לנחש.
- **בלי חיבור:** אם החיבור נופל, מופיעה הודעה, והשינויים נשלחים אוטומטית כשהחיבור חוזר.
